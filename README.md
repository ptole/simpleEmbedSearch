# Simple Embed Search
A small python program that lets you embed all the text in folder's pdf files, and then a simple gui to search for where in the files your given query was.

## Usage
- run dl_and_save_model to download the model used for this project
- run pdf_to_md_to_json_to_embed to convert all pdf files in a given folder to markdown (this takes a while) and to a json file for look-up later
- run simpleEmbedSearch
